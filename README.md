# Python Rock, Paper Scissors

A simple Rock, Paper scissors game built with python.

## Desciption

A console-based game where the player competes againts the computer.
The game keeps track of scores and announces the final champion.

## Features

1. Play againts the computer
2. Random computer chioces 
3. Input validation
4. Track player and computer scores
5. Count ties
6. Display a scoreboard
7. Show the final winner
8. Exit the game

## Technologies

- python 3

- Variables

- conditional statements (if / elif / else)
- Nested conditions
- Logical operators (and)
- Membership operators (not in)
- Comparison operators
- Assignment operators (+=)
- F-Strings

- Break statement

## How to Run

1. Install Python 3
2. Download or clone this repository
3. Open the project folder in your terminal
4. Run the following command: python game.py
